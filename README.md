# TypeFast — ретро-тренажёр скорости печати

Небольшой статический сайт на HTML, CSS и JavaScript. Не использует аккаунты, базу данных, серверную часть или сохранение результатов.

## Запуск на компьютере

1. Скачайте и распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Нажмите «СТАРТ» и начните вводить показанный текст. Таймер стартует с первой введённой буквы.

## Публикация бесплатно через GitHub Pages

1. Войдите на [GitHub](https://github.com/) и создайте новый **публичный** репозиторий, например `typefast`.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js` и `README.md` (кнопка **Add file → Upload files**).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** укажите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Подождите несколько минут. В разделе Pages появится ссылка на опубликованный сайт.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Как считаются результаты

- Скорость: число правильно введённых символов делится на 5 (условная длина слова) и пересчитывается на минуту.
- Ошибки: количество символов, которые не совпадают с исходным текстом в соответствующих позициях, включая лишние символы.
- Время: 60 секунд с первого введённого символа.
- Текст выбирается случайно из небольшого встроенного набора. Результаты после теста не сохраняются.

## Состав проекта

- `index.html` — разметка страницы.
- `style.css` — ретро-оформление и адаптивность.
- `script.js` — тексты, таймер, подсчёт результатов и повтор теста.
